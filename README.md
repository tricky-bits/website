# website

Source content and configuration for the official [Tricky Bits](https://trickybits.dev)
site. This repository holds **only** the site's `tbb.toml` configuration and its
Markdown content (campaigns and pages). The static HTML is produced by the
sibling [`builder`](https://github.com/tricky-bits/builder) tool and published to
GitHub Pages at **https://trickybits.dev**.
